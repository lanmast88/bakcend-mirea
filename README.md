# Система учёта товаров в доме

Консольное приложение для учёта товаров, хранящихся в доме: продуктов,
бытовой химии, лекарств и других предметов. Позволяет фиксировать, какие
товары есть в наличии, в каком количестве и к какой категории они
относятся, чтобы вовремя пополнять запасы и не покупать лишнее.

## Предметная область

Учёт и контроль запасов внутри домохозяйства: регистрация товаров,
привязка их к категориям, отслеживание количества в наличии и изменение
остатков по мере расходования или пополнения запасов.

## Основные сущности

- Пользователь
- Товар
- Количество
- Категория

## Возможности

- авторизация пользователя;
- просмотр и поиск товаров по названию;
- отбор товаров по категории;
- сортировка товаров по остатку;
- добавление товара с указанием категории, количества и порога пополнения;
- списание расхода и пополнение запаса;
- вывод товаров, остаток которых опустился ниже порога.

## Структура проекта

- `main.py` – точка запуска и меню приложения;
- `items.py` – работа с товарами;
- `stock.py` – изменение и контроль остатков;
- `auth.py` – авторизация пользователя;
- `storage.py` – сохранение и загрузка данных;
- `utils.py` – вспомогательные функции ввода;
- `data/` – JSON-файлы данных;
- `tests/` – автоматизированные тесты.

## Хранение данных

Данные хранятся в JSON-файлах каталога `data/`: товары в `items.json`,
пользователи в `users.json`. При запуске программа читает файлы, после
изменения остатков или добавления товара – сохраняет их заново.

## Требования

- Python 3.10+;
- pytest;
- flake8.

Зависимости описаны в `pyproject.toml` (группа `dev`) и продублированы
в `requirements.txt`.

Установка окружения через [uv](https://docs.astral.sh/uv/):

```
uv sync
```

Установка через pip:

```
pip install -r requirements.txt
```

## Запуск программы

```
uv run main.py
```

## Запуск тестов

```
uv run pytest
```

## Проверка качества кода

```
uv run flake8
```

Если окружение активировано (`source .venv/bin/activate`), те же команды
запускаются без префикса `uv run`: `python main.py`, `pytest`, `flake8`.
