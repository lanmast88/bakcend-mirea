# Система учёта товаров в доме

## Назначение

Приложение для учёта товаров, хранящихся в доме: продуктов, бытовой химии, лекарств и других предметов. Позволяет фиксировать, какие товары есть в наличии, в каком количестве и к какой категории они относятся, чтобы вовремя пополнять запасы и не покупать лишнее.

## Целевая аудитория

Домашние пользователи, которые хотят вести учёт домашних запасов: контролировать остатки продуктов и бытовых товаров, отслеживать сроки пополнения и распределять товары по категориям.

## Предметная область

Учёт и контроль запасов внутри домохозяйства: регистрация товаров, привязка их к категориям, отслеживание количества в наличии и изменение остатков по мере расходования или пополнения запасов.

## Основные сущности

- Пользователь
- Товар
- Количество
- Категория

## Основные функции

- регистрация и авторизация пользователя;
- добавление товара с указанием категории и количества;
- уведомление о товарах, количество которых опустилось ниже заданного порога.

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
